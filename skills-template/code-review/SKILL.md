# 代码审查 Skill

当用户说"审查代码"、"code review"、"检查代码"时，使用此 Skill。

## 完整工作流

### 阶段 1: 运行检查

**必须执行：**
1. `npm run lint` - 代码规范检查
2. `npm run build` - 构建检查
3. `npm test` - 运行测试
4. 收集检查结果

### 阶段 2: 审查代码

**必须检查：**
1. 代码规范（按 AGENTS.md 规则）
   - 命名是否一致
   - 是否使用 TypeScript 严格模式
   - 是否有内联样式
2. 安全漏洞
   - 是否有硬编码密钥
   - 是否有 SQL 注入风险
   - 是否有 XSS 风险
3. 性能问题
   - 是否有不必要 re-render
   - 是否有内存泄漏风险
4. 错误处理
   - 是否有未 catch 的异常
   - 是否有合理的错误提示

### 阶段 3: 输出报告

**必须输出：**
```
📋 代码审查报告

🔴 必须修复：
- [问题1及修复建议]
- [问题2及修复建议]

🟡 建议优化：
- [优化建议]

🟢 通过：
- [通过的检查项]
```

### 阶段 4: 执行修复（如需要）

如果用户要求修复：
1. 切换到 Build 模式
2. 按优先级修复问题
3. 重新运行检查确认

## 关键规则

- ✅ 运行完整检查后再报告
- ✅ 提供具体修复建议
- ✅ 按严重程度分类问题
