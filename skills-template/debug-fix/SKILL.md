# Bug 修复 Skill

当用户说"修复bug"、"解决这个问题"、"error"、"崩溃了"时，使用此 Skill。

## 完整工作流

### 阶段 1: 获取错误信息

**必须执行：**
1. 询问用户粘贴完整错误信息
2. 询问相关代码文件或行号
3. 如可能，读取相关文件

### 阶段 2: 分析问题

**必须执行：**
1. 切换到 Plan 模式
2. 分析错误原因：
   - 这是什么类型的错误？（语法/逻辑/运行时/类型）
   - 可能的原因是什么？
3. 提出修复方案

### 阶段 3: 实施修复

**必须执行：**
1. 切换到 Build 模式
2. 应用修复
3. 运行测试验证

### 阶段 4: 记录学习

**必须执行：**
1. 更新 `lessons.md` 记录：
   - 错误现象
   - 根本原因
   - 解决方式
   - 预防措施
2. 更新 `progress.txt`（如有需要）

## 输出格式

完成后告诉用户：
```
✅ Bug 已修复！

🔍 问题分析：
- [错误原因]

🔧 解决方案：
- [修复方式]

📝 已记录到 lessons.md

继续工作或还有其它问题？
```

## 关键规则

- ❌ 不要盲目尝试修复
- ✅ 先分析再动手
- ✅ 修复后必须验证
- ✅ 必须记录到 lessons.md
