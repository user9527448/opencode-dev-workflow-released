## 2. 用户流程

### 2.1 认证流程

```
[未登录]
    │
    ▼
访问任意需要认证的页面
    │
    ▼
重定向到 /login
    │
    ├── [已注册] → 输入账号密码 → 登录成功 → 重定向到 /dashboard
    │
    └── [未注册] → 点击注册 → /register → 填写信息 → 注册成功 → 登录 → /dashboard
```

### 2.2 核心功能流程

```
[用户已登录]
    │
    ▼
访问 /dashboard
    │
    ├── 查看概览
    │
    ├── 点击「创建」→ /create → 填写表单 → 提交 → 成功提示 → 返回列表
    │
    └── 点击任意项目 → /detail/:id → 查看详情
                              ├── 编辑 → /edit/:id → 保存 → 返回详情
                              └── 删除 → 确认弹窗 → 删除成功 → 返回列表
```

## 3. 页面详情

### 3.1 首页 (/)

**页面元素：**
- Logo
- 主标题
- 副标题
- 行动按钮（CTA）：「开始使用」/「了解更多」
- 底部导航

**用户操作：**
- 点击 CTA → /login 或 /register（未登录）→ /dashboard（已登录）

**状态：**
- 加载状态：骨架屏
- 空状态：N/A

---

### 3.2 登录页 (/login)

**页面元素：**
- Logo
- 用户名输入框
- 密码输入框
- 登录按钮
- 第三方登录按钮（Google/GitHub）
- 注册链接
- 忘记密码链接

**用户操作：**
- 输入账号密码 → 点击登录 → 验证 → 跳转
- 点击第三方登录 → OAuth 流程
- 点击注册 → /register
- 点击忘记密码 → /forgot-password

**状态：**
- 加载状态：按钮 loading
- 错误状态：错误提示文案
- 成功状态：跳转至 /dashboard

---

### 3.3 仪表盘 (/dashboard)

**页面元素：**
- 顶部导航栏
- 侧边栏导航
- 主内容区
  - 统计卡片
  - 最近活动列表
  - 快捷操作

**用户操作：**
- 点击侧边栏 → 切换功能区
- 点击操作 → 执行对应操作

**状态：**
- 加载状态：骨架屏
- 空状态：「暂无数据」提示
- 错误状态：错误提示

## 4. 边缘情况

| 场景 | 处理方式 |
|------|----------|
| 未登录访问需要认证的页面 | 重定向到 /login |
| 登录过期 | 弹窗提示，点击确定跳转 /login |
| 网络错误 | 显示错误提示，提供重试按钮 |
| 权限不足 | 显示 403 页面 |
